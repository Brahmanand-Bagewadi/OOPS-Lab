## Learning Areas

The laboratory work in this repository focuses on understanding and
implementing the following Object Oriented Programming concepts using C++.

### Fundamental Programming Concepts
- Programming fundamentals
- Arrays and strings
- Functions and methods
- Parameter passing techniques

### Classes and Objects
- Classes and objects
- Data members and member functions
- Scope resolution operator
- Encapsulation and data hiding
- Access / visibility modifiers
- Constructors and destructors
- Static data members
- Inline functions
- Friend classes and friend functions
- Nested classes
- Passing objects as function arguments
- UML representation of classes

### Inheritance
- Basic inheritance concepts
- Types of inheritance
- Base and derived classes
- Access specifiers
- Constructors in inheritance
- Constructor initialization lists
- Member and nested classes
- Virtual base classes
- Inheriting private members

### Polymorphism
- Compile-time and run-time polymorphism
- Virtual functions
- Pure virtual functions
- Abstract classes
- Reference variables
- Static functions
- `this` pointer
- Operator overloading

### Exception Handling
- Exception handling concepts
- `try`, `throw` and `catch`
- Handling multiple exceptions
- Exceptions with arguments
- Built-in exception classes

### Templates and File Handling
- Function templates
- Class templates
- C++ I/O streams
- File streams
- Text file handling
- Binary file handling
- Error handling during file operations
